## 1. מה הפרויקט

**JobHunter** — מערכת אישית שעוזרת למשתמש למצוא משרת סטודנט. המשתמש: סטודנט שנה ג' להנדסת תוכנה (B.Sc), מסיים ב-2028, מחפש משרת סטודנט בפיתוח תוכנה / R&D / AI, בדרום או במרכז, עד 3 ימים בשבוע.

**איך זה עובד, בכל בוקר:**
1. **תתי-סוכנים** (קוד Python בלבד) מושכים משרות מאתרי חברות ומאתרי חיפוש משרות, משתמשים בפילטרים של כל אתר, ומעבירים רק משרות שלא ראו בעבר.
2. **הסוכן הגדול** (Claude) קורא כל משרה חדשה, בונה לה כרטיס, בודק אותה מול החיפוש של המשתמש, מוריד כפילויות, כותב ללוח המשרות, ושולח התראה.
3. **המשתמש** נכנס ללוח, מסמן סטטוסים (הוגש / בהמתנה / לא מעוניין...), ומגיש.

**עקרונות שהוחלטו:**
- **אישי בלבד**, רץ על **Claude Pro של המשתמש** — בלי עלות נוספת. הריצה **מקומית** על המחשב שלו (לא בענן).
- **החיפוש הוא נתון, לא קוד.** כשהמשתמש יחפש משרה מסוג אחר (ג'וניור, סניור), משנים את `docs/search.md` ואת סט הזהב — לא את הקוד. בשום מקום בקוד או בפרומפטים לא כתוב מקצוע או רמה.
- **המוח (Claude) נפרד מהכלים (Python)** — כדי שבעתיד אפשר יהיה להעביר את המוח ל-API (למשל לגרסה למשתמשים נוספים) בלי לכתוב מחדש.
- **הסוכן מכין, המשתמש מגיש.** אין שליחה אוטומטית, ואסור להמציא מידע.
- **מקורות:** רק **אתרי חברות** (39 חברות) ו**אתרי חיפוש משרות** (HireMeTech, SecretHunter, Glassdoor). קבוצות וואטסאפ / טלגרם / פייסבוק **הוצאו** — הן ממילא מפנות לאתרי החיפוש.

2. תמונת מצב של הלוח ← `state/board/` (לא ב-git).
3. `python -m jobhunter.morning plan` ← `state/plan/<תאריך>.json`: מועמדים לכפילות לכל משרה + משרות לדחיסה (כלל 30 יום).
4. המוח: כרטיס לכל משרה בלי התאמה ודאית, הכרעה במקרי גבול, כתיבה ללוח.
5. שורת ריצה ב-`runs`, התראה, `git push` של `state/seen` ו-`state/inbox` כגיבוי.

## 6. מה עשינו עד עכשיו (בקצרה, לפי הסדר)

## 9. מלכודות שכבר נלמדו

- **נתיב ה-scratchpad ארוך מדי** ל-Python וליצירת venv ב-Windows (מגבלת 260 תווים). קבצים זמניים — ב-`state/plan/` (לא ב-git).
- **SmartRecruiters** מחזיר HTTP 200 גם לחברה שלא קיימת — לבדוק `totalFound`.
- **Workday** — חיפוש: POST ל-`https://<host>/wday/cxs/<tenant>/<site>/jobs`.
- **Elbit** מחזיר 403; **Rafael** — העמוד נבנה בדפדפן ומגיע ריק.
- **מסד הנתונים של הלוח:** `update` מחליף מערך שלם; כל כתיבה למסמך קיים צריכה `if_version`.
- **הסקה:** תחנת רכבת או תיאור משרדי החברה אינם מקור למיקום המשרה (התברר בטעות על משרה #1).
- **ב-Windows PowerShell 5.1** — פלט Python עם עברית צריך `PYTHONIOENCODING=utf-8` (ב-Bash).
