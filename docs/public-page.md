# האתר הציבורי — הלוח ב-GitHub Pages

**https://kalma57.github.io/JobHunter/** (16/10/2026)

## מה זה
הלוח עצמו, פתוח לכולם: לשוניות (חדש, בהמתנה, הגשתי, לא מעוניין, סוננו, נסגרו), כרטיס מלא לכל משרה, דוח הבוקר (מספרים + מה סונן בקוד ולמה) ו"על המערכת".
**החלטת המשתמש (16/10):** הכל גלוי למבקרים, כולל סטטוסים והערות. רק הבעלים יכול לשנות.

## איך רק הבעלים משנה
- "כניסת בעלים" ← מדביקים מפתח GitHub אישי (fine-grained token, ריפו `Kalma57/JobHunter` בלבד, Contents: Read and write). המפתח נשמר רק ב-localStorage של הדפדפן, לא נשלח לשום מקום חוץ מ-api.github.com.
- כל סימון (הגשתי, בהמתנה, לא מעוניין + סיבה, הערות, קישור הגשה) נשמר ל-`statuses.json` בענף `board-data` דרך ה-GitHub API, כ-commit.
- מבקרים בלי מפתח רואים הכל בלי כפתורים.

## איך זה מתחבר לריצת הבוקר
- `jobhunter/overlay.py` קורא את `statuses.json` (git fetch של `board-data`) ומלביש אותו על הכרטיסים מהלוח של claude.ai. הסטטוס של המשתמש קובע, אלא אם לכרטיס יש אירוע חדש יותר (למשל "נסגרה" מהבוקר). אותו כלל בדף (`mergeMark`).
- `morning prepare` משתמש בזה לכפילויות ולסגירות — משרה שסימנת לא חוזרת כחדשה, ומשרה שהגשת לא נסגרת.
- `morning finish` בונה את `public/index.html` (התבנית `site/public.html`, כל הכרטיסים + הסימונים של הבוקר) ומעלה ל-`gh-pages`. כשהדף נפתח הוא מושך את הסימונים העדכניים.

## ענפים
`main` — הקוד והגיבוי · `gh-pages` — הדף (היסטוריה נפרדת, רק `index.html`) · `board-data` — `statuses.json` בלבד.
