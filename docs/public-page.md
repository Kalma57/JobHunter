## מה יש בו
- **הבוקר במספרים** — כמה מקורות נקראו, כמה משרות בישראל נסרקו, כמה חדשות, כמה סוננו בקוד, כמה קרא Claude, וכמה מתאימות כרגע. מספרים אמיתיים מהריצה האחרונה.
- **משרות פתוחות שמתאימות** — שם, חברה, מקום, רמת התאמה, תגיות (Python / Java / AI), תאריך, קישור.
- **איך זה עובד** — ארבעה שלבים, ורשימת המקורות שנקראו.
- שם, תפקיד וקישורים מ-`config/public.json` (קישורי LinkedIn / GitHub — למלא).

## מה אין בו (פרטיות)
אין סטטוסים (הוגש / בהמתנה / לא מעוניין), אין הערות, אין תאריכי הגשה, אין משרות שסוננו או נסגרו, ואין את סט הזהב. בדיקה: `tests/test_pipeline.py`.
