# כרטיס משרה — הגדרה (שלב 1, סגור 08/10/2026)

השפה המשותפת לכל הסוכנים. כל תת-סוכן מחזיר משרה בפורמט הזה, לא משנה מאיפה הגיעה.

## כללים לכל השדות
1. **"לא צוין"** — לכל שדה. הסוכן לא מנחש. "לא צוין" ≠ ערך מפורש (למשל "ללא צורך בניסיון" הוא מידע).
2. **רשימה + "אחר"** — לכל שדה עם אפשרויות יש גם טקסט חופשי. ערכים שחוזרים ב"אחר" נוסיף לרשימה מדי פעם.
3. **מפורש / הוסק** — מותר לסוכן להסיק מידע שלא נכתב, אבל הוא מסומן "הוסק ע"י הסוכן" + הערה שמסבירה למה, ומוצג **בצבע אחר**.
4. **הטקסט המקורי נשמר תמיד** — כדי שאפשר יהיה לסרוק מחדש.
5. **טווחים חופפים עוברים** — משרה של "2-4 ימים" עוברת חיפוש של "עד 3 ימים", כי יש חפיפה.
6. **זהירות בהסקה** — הסקה מרמזים עקיפים (למשל עיר לפי תחנת רכבת) לא אמינה: במשרה #1 הוסק "תל אביב" מתחנת סבידור, והמשרה בפועל ברמת גן.
7. **כללי לכל מקצוע** — אין בכרטיס שום דבר ספציפי לתוכנה. מה שספציפי לתחום נכנס ל"שדות לפי תחום".

## החיפוש: חובה / העדפה
- כל דרישה בחיפוש מסומנת **חובה** (לא עומדת ← נפסלת) או **העדפה** (משפיעה רק על הדירוג).
- **דרישת חובה על שדה שלא צוין במודעה ← המשרה עוברת**, עם סימון "לא צוין". עדיף לקבל אקסטרה מלאבד פוטנציאל.
- החיפוש מוגדר בסוכן הגדול ונורש לכל תתי-הסוכנים; תת-סוכן יכול להוסיף דרישות למקור שלו. (המלצה — לאישור סופי)

### איך מגישים ומי פרסם
| שדה | אפשרויות | הערות |
|---|---|---|
| דרך הגשה | קישור, טופס באתר, מייל, וואטסאפ, טלפון, "בפרטי", חבר מביא חבר | |
| הנחיות הגשה מיוחדות | טקסט | "לצרף גיליון ציונים ב-PDF אחד עם הקו"ח" |
| איש קשר | שם + פרטי התקשרות | |
| מי פרסם | החברה, חברת השמה (+ שם), עובד/ת בחברה, לא ידוע | המפרסם ≠ תמיד המעסיק |
| מספר משרה | טקסט | סימן חזק לכפילות |

| קישור הגשה (`apply_url`) | URL | קישור **ישיר** להגשה, אם שונה מעמוד המשרה. בלוח: כפתור "הגשה ↗" |
| תאריך פרסום | תאריך | יחסי ("לפני 3 ימים") ← מחושב מתאריך האיסוף. **יותר מ-60 יום ← התראה "משרה ישנה"** |
| תאריך אחרון להגשה | תאריך | |

### שדות מערכת (לא מהמודעה)
מקור (סוכן/קבוצה/אתר), תאריך איסוף, טקסט מקורי, סטטוס (חדש / נשמר / לא רלוונטי / הוגש / נסגר), קישור למשרה המקורית אם כפילות, החלטת רלוונטיות + נימוק, **התראות** (סתירה במודעה, משרה ישנה).

## לקחים מבדיקת 8 המשרות
- אתרים מתייגים לא נכון (משרה של 3 שנות ניסיון מתויגת Student; "communication" כטכנולוגיה) — המוח קורא את הטקסט, לא סומך על תגיות.
- המפרסם לא תמיד המעסיק (חברת השמה בשם חברה חסויה).
- הרבה רעש באתרים (פרימיום, רפרלים, הסתייגויות משפטיות) — הכלים צריכים לנקות.
- סוכן שיושב על אתר יראה יותר מהעתק-הדבק: לוגו (כשאין שם חברה בטקסט), תמונות. בכל פרומפט דרישות נשאל "מה הסוכן רואה — טקסט בלבד או גם תמונות".
