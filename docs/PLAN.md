# JobHunter — תכנית עבודה

(גרסה 3, 09/10/2026 — גרסה אישית שרצה על Claude Pro.)

## החזון
מערכת אישית שכל בוקר סורקת אתרי משרות ואתרי חברות, מסננת לפי מה שאני מחפש, מורידה כפילויות, עוקבת אחרי ההגשות שלי, ושולחת לי סיכום במייל.
- **רצה על Claude Pro** (Routines) — בלי עלות נוספת.
- **החיפוש הוא נתון, לא קוד:** כשאחפש משרה מסוג אחר, משנים את `search.md` ואת סט הזהב — לא את הקוד.
- **המוח (Claude) נפרד מהכלים (קוד Python)** — כדי שבעתיד אפשר יהיה להעביר את המוח ל-API (למשל לגרסה למשתמשים נוספים) בלי לכתוב מחדש.

## מחזור העבודה בכל שלב
1. **פרומפט דרישות** (בשלבי סוכנים) — המשתמש מגדיר מה הוא דורש.
2. **מסכימים על הבדיקה לפני שבונים.**
3. **מציגים תכנון:** אילו מחלקות, מה כל אחת עושה, באילו ספריות — המשתמש מאשר.
4. **בונים** — מחלקה אחת בכל פעם.
5. **מריצים את הבדיקה ומציגים תוצאות** — עוברים הלאה רק אחרי אישור.
